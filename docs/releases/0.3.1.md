Paperboy now ships public Docker releases for Linux and Unraid, with simple update controls in Settings.

- Install published AMD64 or ARM64 images without compiling or signing into GitHub.
- Choose manual updates, opt into automatic updates, or pin each server to a chosen version.
- Updates wait for active printing, preserve settings and queues, check service health, and recover interrupted replacements.
- This patch keeps Docker's cached stable/latest images current after upgrades, retries temporary download failures, and protects published version tags from replacement.
- Update progress now stays visible until the companion finishes. Saved update records receive stricter identity checks.
- The Settings interface follows Taste Skill's preserve-mode guidance and Paperboy's minimal Apple-inspired design.

Download and run `install.sh` in an empty persistent folder, then start:

```sh
docker compose -f compose.release.yaml -f compose.linux.yaml --profile updates up -d
```

Open `http://YOUR-SERVER-IP:8025`. Automatic updates are off until enabled in **Settings → Updates**.

See the [installation and update guide](https://github.com/thekozugroup/Paperboy/blob/main/docs/updates.md) for Unraid, Linux, version pins, and recovery.

Physical output and live Resend delivery still require your configured account and printer. Document conversion uses isolated LibreOffice/Poppler alongside the Rust services.
