Paperboy's first packaged release. Install on a Linux server or Unraid without compiling from source.

- Public Docker images for Linux AMD64 and ARM64, including the isolated document converter.
- Settings shows the installed version, available stable releases, and release notes.
- An optional native Rust updater supports manual installation and automatic updates per server.
- Pin a server to a specific version with `PAPERBOY_PIN_VERSION`; other servers can continue receiving releases.
- Updates download both images, wait for active prints, retain saved settings/queue/printer volumes, verify health, and restore the previous containers if startup fails. The updater replaces itself last.
- Existing sender authentication, approval checks, conversion isolation, and duplicate prevention remain in place.

Download the Compose files or run the attached installer in an empty directory. Start with:

```sh
docker compose -f compose.release.yaml -f compose.linux.yaml --profile updates up -d
```

Open `http://YOUR-SERVER-IP:8025`. Enter the setup code from `docker compose -f compose.release.yaml logs paperboy`. Turn on **Settings → Updates → Automatic updates** if desired. Updates are manual by default.

See the repository's [installation and update guide](https://github.com/thekozugroup/Paperboy/blob/main/docs/updates.md) for socket-group setup, Unraid persistence, version pins, and recovery.

Physical output and a real Resend account still require acceptance on your own printer. Broad document conversion is provided by isolated LibreOffice/Poppler alongside the native Rust services.
