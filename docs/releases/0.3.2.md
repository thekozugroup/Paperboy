# Paperboy 0.3.2

This patch fixes two causes of valid emailed PDFs failing before printing.

- Accept attachment downloads from Resend's exact `cdn.resend.app` host. HTTPS,
  public-address validation, DNS pinning, redirect/proxy denial and size limits remain.
- Read PDF page dimensions without mistaking `File size:` bytes for a page dimension.
  Ordinary PDFs over 14,400 bytes can convert; oversized pages remain rejected.
- Add regression checks for the CDN, deceptive hosts, larger PDFs and oversized pages.

Owner access, approved senders, settings and queue data are preserved. Existing
installations with automatic updates enabled receive this patch through the companion
updater after active printing finishes.

Native tests, Docker conversion and software-printer checks passed. Physical printer
output depends on the configured printer; no physical printing claim is made here.
